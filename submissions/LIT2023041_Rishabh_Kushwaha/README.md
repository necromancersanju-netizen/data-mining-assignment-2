# Book Recommender System

**Name:** Rishabh Kushwaha  
**Roll No.:** LIT2023041  

Book-Crossing recommender system built with a Bronze → Silver → Gold medallion data lake and item-based collaborative filtering (cosine similarity).

- **Notebook:** `Rishabh_Kushwaha_Book_Recommender_System.ipynb`
- **How to run:** Open the notebook and run all cells top-to-bottom. It downloads `book-crossings.zip` and creates `bronze/`, `silver/`, and `gold/` in the working directory.
