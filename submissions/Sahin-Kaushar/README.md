
# Book Recommender System

**Student:** Sahin Kaushar  
**College:** IIIT Lucknow

## Project Overview
A book recommendation system using the Book-Crossing dataset and Medallion Data Lake architecture.

## Technologies
- Python
- Pandas
- NumPy
- SciPy
- Scikit-learn
- Google Colab

## Project Workflow
1. Bronze Layer – Data ingestion.
2. EDA – Exploratory data analysis.
3. Silver Layer – Data cleaning.
4. Gold Layer – Sparse rating matrix and aggregates.
5. Recommender System – Item-Based Collaborative Filtering.
6. Demo – Testing recommendations for three users.

## Dataset Statistics
- Users: 1,820
- Books: 2,030
- Ratings: 41,456
- Matrix sparsity: 98.8779%

## Recommendation Algorithm
Cosine similarity-based Item-Based Collaborative Filtering.
